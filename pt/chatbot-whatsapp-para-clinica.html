Perguntas frequentes

O chatbot dá orientação médica?

Não. Ele responde só informações da clínica (horários, convênios, valores) e passa o resto para a equipe.

E os dados dos pacientes?

O chatbot pede só o necessário para o agendamento. Combinamos antes onde esses dados ficam e quem tem acesso.

Posso continuar usando o mesmo número no celular?

O número ligado ao bot passa para a API oficial do WhatsApp e deixa de funcionar no aplicativo. Se você quer manter os dois, existe um serviço à parte para isso, e explicamos o custo antes. Outra opção é um número novo só para o bot.

Como faço o pagamento?

Pela Workana: o valor fica retido na plataforma e só é liberado quando você aprova a entrega. Dá para pagar com cartão e PayPal.
